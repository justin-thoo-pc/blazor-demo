# Blazor Parts Manager — Bake-Off Project Plan

**Framework**: Blazor Web App (.NET 9/10)  
**Project Scope**: Single-screen CRUD app (Parts Manager)  
**Time-box**: ½–1 day (based on document)  
**Render Mode**: Auto (hybrid — mix of Server and WebAssembly per component)  
**Baseline Completion**: All 15 acceptance criteria + 1 unit test

---

## Executive Summary

This is a structured plan to build the Parts Manager CRUD app in Blazor as part of the front-end framework bake-off. You'll build a complete app shell with Header, Sidebar, and Content area, implement a data grid with sort/filter/pagination, and a modal form with inline validation — all talking to the shared json-server mock API.

**Advantage**: C# end-to-end, strong typing, reuse of backend models.  
**Key Decision**: Render mode (Server vs WebAssembly vs Auto) — we recommend **Auto** (hybrid) to keep page load fast while keeping interactivity on the client.

### 2.2 Create the API service

Create `Services/PartsService.cs`:

```csharp
namespace PartsBlazor.Services;

using System.Net.Http.Json;
using PartsBlazor.Models;

public class PartsService(HttpClient httpClient)
{
    private const string ApiUrl = "http://localhost:4000/parts";

    // Fetch paginated parts
    public async Task<(List<Part> Items, int Total)> GetPartsAsync(
        int page = 1, 
        int limit = 10, 
        string? sortBy = null, 
        string? filter = null,
        string? categoryFilter = null,
        CancellationToken ct = default)
    {
        var url = $"{ApiUrl}?_page={page}&_limit={limit}";
        if (!string.IsNullOrEmpty(sortBy))
            url += $"&_sort={sortBy}";
        if (!string.IsNullOrEmpty(filter))
            url += $"&q={filter}";
        if (!string.IsNullOrEmpty(categoryFilter))
            url += $"&category={categoryFilter}";

        var response = await httpClient.GetAsync(url, ct);
        response.EnsureSuccessStatusCode();

        var parts = await response.Content.ReadAsAsync<List<Part>>(cancellationToken: ct) 
            ?? new();
        
        // json-server returns total count in X-Total-Count header
        var total = int.TryParse(
            response.Headers.FirstOrDefault(h => h.Key == "X-Total-Count").Value?.FirstOrDefault(), 
            out var t) ? t : parts.Count;

        return (parts, total);
    }

    // Create a new part
    public async Task<Part?> CreatePartAsync(Part part, CancellationToken ct = default)
    {
        var response = await httpClient.PostAsJsonAsync(ApiUrl, part, ct);
        response.EnsureSuccessStatusCode();
        return await response.Content.ReadAsAsync<Part>(cancellationToken: ct);
    }

    // Update an existing part
    public async Task<Part?> UpdatePartAsync(string id, Part part, CancellationToken ct = default)
    {
        var response = await httpClient.PutAsJsonAsync($"{ApiUrl}/{id}", part, ct);
        response.EnsureSuccessStatusCode();
        return await response.Content.ReadAsAsync<Part>(cancellationToken: ct);
    }

    // Delete a part
    public async Task DeletePartAsync(string id, CancellationToken ct = default)
    {
        var response = await httpClient.DeleteAsync($"{ApiUrl}/{id}", ct);
        response.EnsureSuccessStatusCode();
    }

    // Get categories (hardcoded for demo)
    public List<string> GetCategories() => 
        Enum.GetNames(typeof(PartCategory)).ToList();
}
```

### 4.1 Data grid / table

Create `Components/UI/PartsGrid.razor`:

```razor
@using PartsBlazor.Models
@using PartsBlazor.Services
@inject PartsService PartsService

@rendermode InteractiveServer

<div class="grid-container">
    <div class="grid-toolbar">
        <input type="text" placeholder="Filter by SKU or Name..." @bind="filterText" />
        <select @bind="categoryFilter">
            <option value="">All Categories</option>
            @foreach (var cat in categories)
            {
                <option value="@cat">@cat</option>
            }
        </select>
        <button @onclick="ResetFilters">Reset</button>
        <button class="btn-primary" @onclick="() => ShowAddForm = true">+ Add Part</button>
    </div>

    @if (isLoading)
    {
        <div class="state-empty">Loading parts...</div>
    }
    else if (parts.Count == 0)
    {
        <div class="state-empty">No parts found. <a href="#" @onclick="() => ShowAddForm = true">Add one now.</a></div>
    }
    else if (hasError)
    {
        <div class="state-error">Failed to load parts. <button @onclick="LoadParts">Retry</button></div>
    }
    else
    {
        <table class="parts-table">
            <thead>
                <tr>
                    <th><a href="#" @onclick="@((e) => SortBy("sku"))">SKU</a></th>
                    <th><a href="#" @onclick="@((e) => SortBy("name"))">Name</a></th>
                    <th><a href="#" @onclick="@((e) => SortBy("category"))">Category</a></th>
                    <th><a href="#" @onclick="@((e) => SortBy("price"))">Price</a></th>
                    <th><a href="#" @onclick="@((e) => SortBy("stock"))">Stock</a></th>
                    <th>Status</th>
                    <th>Actions</th>
                </tr>
            </thead>
            <tbody>
                @foreach (var part in parts)
                {
                    <tr>
                        <td>@part.Sku</td>
                        <td>@part.Name</td>
                        <td>@part.Category</td>
                        <td>$@part.Price.ToString("0.00")</td>
                        <td>@part.Stock</td>
                        <td><span class="badge @(part.Active ? "active" : "inactive")">@(part.Active ? "Active" : "Inactive")</span></td>
                        <td>
                            <button class="btn-sm" @onclick="() => EditPart(part)">Edit</button>
                            <button class="btn-sm btn-danger" @onclick="() => ConfirmDelete(part)">Delete</button>
                        </td>
                    </tr>
                }
            </tbody>
        </table>

        <div class="pagination">
            <button @onclick="PreviousPage" disabled="@(currentPage == 1)">← Prev</button>
            <span>Page @currentPage of @totalPages</span>
            <button @onclick="NextPage" disabled="@(currentPage >= totalPages)">Next →</button>
        </div>
    }

    @if (ShowAddForm)
    {
        <PartsForm Part="editingPart" OnSave="SavePart" OnCancel="CancelEdit" />
    }

    @if (showDeleteConfirm)
    {
        <ConfirmDialog 
            Message="@($"Delete part '{partToDelete?.Name}'? This cannot be undone.")" 
            OnConfirm="ConfirmDeletePart" 
            OnCancel="CancelDelete" />
    }
</div>

@code {
    private List<Part> parts = new();
    private List<string> categories = new();
    private Part? editingPart;
    private Part? partToDelete;
    
    private bool ShowAddForm = false;
    private bool showDeleteConfirm = false;
    private bool isLoading = true;
    private bool hasError = false;
    
    private int currentPage = 1;
    private int totalPages = 1;
    private string filterText = "";
    private string categoryFilter = "";
    private string? sortField = null;

    protected override async Task OnInitializedAsync()
    {
        categories = PartsService.GetCategories();
        await LoadParts();
    }

    private async Task LoadParts()
    {
        try
        {
            isLoading = true;
            hasError = false;
            var (loadedParts, total) = await PartsService.GetPartsAsync(
                currentPage, 10, sortField, 
                string.IsNullOrEmpty(filterText) ? null : filterText,
                string.IsNullOrEmpty(categoryFilter) ? null : categoryFilter);
            
            parts = loadedParts;
            totalPages = (total + 9) / 10; // ceiling division
        }
        catch
        {
            hasError = true;
        }
        finally
        {
            isLoading = false;
        }
    }

    private async Task SortBy(string field)
    {
        sortField = sortField == field ? null : field;
        currentPage = 1;
        await LoadParts();
    }

    private void EditPart(Part part)
    {
        editingPart = new Part 
        { 
            Id = part.Id, Sku = part.Sku, Name = part.Name, 
            Category = part.Category, Price = part.Price, 
            Stock = part.Stock, Active = part.Active 
        };
        ShowAddForm = true;
    }

    private async Task SavePart(Part part)
    {
        try
        {
            if (string.IsNullOrEmpty(part.Id))
            {
                await PartsService.CreatePartAsync(part);
            }
            else
            {
                await PartsService.UpdatePartAsync(part.Id, part);
            }
            ShowAddForm = false;
            editingPart = null;
            await LoadParts();
        }
        catch
        {
            hasError = true;
        }
    }

    private void CancelEdit()
    {
        ShowAddForm = false;
        editingPart = null;
    }

    private void ConfirmDelete(Part part)
    {
        partToDelete = part;
        showDeleteConfirm = true;
    }

    private async Task ConfirmDeletePart()
    {
        if (partToDelete != null)
        {
            try
            {
                await PartsService.DeletePartAsync(partToDelete.Id);
                showDeleteConfirm = false;
                partToDelete = null;
                await LoadParts();
            }
            catch
            {
                hasError = true;
                showDeleteConfirm = false;
            }
        }
    }

    private void CancelDelete()
    {
        showDeleteConfirm = false;
        partToDelete = null;
    }

    private async Task PreviousPage()
    {
        if (currentPage > 1)
        {
            currentPage--;
            await LoadParts();
        }
    }

    private async Task NextPage()
    {
        if (currentPage < totalPages)
        {
            currentPage++;
            await LoadParts();
        }
    }

    private async Task ResetFilters()
    {
        filterText = "";
        categoryFilter = "";
        sortField = null;
        currentPage = 1;
        await LoadParts();
    }
}
```

### 4.2 Form component with validation

Create `Components/UI/PartsForm.razor`:

```razor
@using PartsBlazor.Models
@using System.ComponentModel.DataAnnotations

@rendermode InteractiveServer

<div class="modal-overlay" @onclick="OnCancel">
    <div class="modal-content" @onclick:stopPropagation>
        <div class="modal-header">
            <h3>@(Part?.Id == null ? "Add Part" : "Edit Part")</h3>
            <button class="close-btn" @onclick="OnCancel">✕</button>
        </div>

        <form @onsubmit="HandleSubmit">
            <div class="form-group">
                <label>SKU *</label>
                <input type="text" @bind="Part.Sku" disabled="@isSubmitting" 
                       placeholder="e.g., ABC-001" />
                @if (!IsValidSku())
                {
                    <span class="error">SKU is required and must be 3-20 characters</span>
                }
            </div>

            <div class="form-group">
                <label>Name *</label>
                <input type="text" @bind="Part.Name" disabled="@isSubmitting" 
                       placeholder="e.g., Bearing A1" />
                @if (!IsValidName())
                {
                    <span class="error">Name is required and max 80 characters</span>
                }
            </div>

            <div class="form-group">
                <label>Category *</label>
                <select @bind="Part.Category" disabled="@isSubmitting">
                    <option value="">-- Select --</option>
                    @foreach (var cat in categories)
                    {
                        <option value="@cat">@cat</option>
                    }
                </select>
                @if (string.IsNullOrEmpty(Part.Category))
                {
                    <span class="error">Category is required</span>
                }
            </div>

            <div class="form-group">
                <label>Price ($) *</label>
                <input type="number" @bind="Part.Price" disabled="@isSubmitting" 
                       placeholder="0.00" step="0.01" />
                @if (Part.Price <= 0)
                {
                    <span class="error">Price must be greater than 0</span>
                }
            </div>

            <div class="form-group">
                <label>Stock (Units) *</label>
                <input type="number" @bind="Part.Stock" disabled="@isSubmitting" 
                       placeholder="0" min="0" />
                @if (Part.Stock < 0)
                {
                    <span class="error">Stock cannot be negative</span>
                }
            </div>

            <div class="form-group checkbox">
                <input type="checkbox" @bind="Part.Active" disabled="@isSubmitting" />
                <label>Active</label>
            </div>

            <div class="form-actions">
                <button type="button" @onclick="OnCancel" disabled="@isSubmitting" class="btn-secondary">Cancel</button>
                <button type="submit" disabled="@(!IsFormValid() || isSubmitting)" class="btn-primary">
                    @(isSubmitting ? "Saving..." : "Save")
                </button>
            </div>
        </form>
    </div>
</div>

@code {
    [Parameter]
    public Part Part { get; set; } = new();

    [Parameter]
    public EventCallback<Part> OnSave { get; set; }

    [Parameter]
    public EventCallback OnCancel { get; set; }

    private List<string> categories = new();
    private bool isSubmitting = false;

    protected override void OnInitialized()
    {
        if (Part.Category == null)
            Part.Category = "";
    }

    private bool IsValidSku() => !string.IsNullOrWhiteSpace(Part.Sku) && 
                                 Part.Sku.Length >= 3 && Part.Sku.Length <= 20;
    
    private bool IsValidName() => !string.IsNullOrWhiteSpace(Part.Name) && 
                                  Part.Name.Length <= 80;
    
    private bool IsFormValid() => IsValidSku() && IsValidName() && 
                                  !string.IsNullOrEmpty(Part.Category) && 
                                  Part.Price > 0 && Part.Stock >= 0;

    private async Task HandleSubmit()
    {
        if (!IsFormValid()) return;
        
        isSubmitting = true;
        try
        {
            await OnSave.InvokeAsync(Part);
        }
        finally
        {
            isSubmitting = false;
        }
    }
}
```

## Phase 4.7: Understanding Blazor Routing

### How Routing Works in Blazor

Blazor uses **file-based routing** similar to Next.js. Here's how it works:

**1. Page Component Declaration**
Every page file in `Components/Pages/` must have a `@page` directive:

```razor
@page "/"           // Matches root URL
@page "/home"       // Alternative route for same component

@page "/parts"      // Single route

@page "/contact"    // Single route
```

**2. Route Matching**
- When you navigate to `http://localhost:5000/`, Blazor looks for a component with `@page "/"`
- When you navigate to `http://localhost:5000/parts`, it looks for `@page "/parts"`
- **Multiple @page directives** = component responds to multiple URLs (great for aliases)

**3. Navigation Methods**

**Method A: HTML Links** (automatic client-side navigation)
```razor
<a href="/parts">Go to Parts</a>
<a href="/">Home</a>
```

**Method B: Programmatic Navigation** (C# code)
```csharp
@inject NavigationManager Navigation

// In C# code block
Navigation.NavigateTo("/parts");
Navigation.NavigateTo("/");
```

**Method C: Sidebar with Active State** (what we built)
```razor
@inject NavigationManager Navigation

<a href="/parts" class="@(IsActive('/parts') ? "active" : "")">Parts</a>

@code {
    private bool IsActive(string path) => Navigation.Uri.EndsWith(path);
}
```

### Route Parameters (Optional Enhancement)

If you wanted dynamic routes (e.g., `/part/123`), you'd use parameters:

```razor
@page "/part/{PartId}"

<h1>Part Details for @PartId</h1>

@code {
    [Parameter]
    public string PartId { get; set; } = string.Empty;

    protected override async Task OnInitializedAsync()
    {
        // Load part with ID
        var part = await PartsService.GetPartAsync(PartId);
    }
}
```

### File Structure Summary

Your routing structure looks like this:

```
Components/Pages/
├── Home.razor              @page "/" and @page "/home"
├── PartsManager.razor      @page "/parts"
├── ContactUs.razor         @page "/contact"
├── Reports.razor           @page "/reports"  (placeholder)
└── Settings.razor          @page "/settings" (placeholder)
```

Each `.razor` file is automatically a routable page. Blazor's router (in `App.razor`) matches incoming URLs to these `@page` directives at runtime.

### Why This Matters for the Bake-Off

**Blazor's routing story:**
- ✅ Declarative (`@page` directive is intuitive)
- ✅ File-based (organized structure)
- ✅ Fast client-side navigation (no full page reload)
- ✅ Built-in (no extra package needed like React Router)
- ⚠️ Requires understanding of NavigationManager for dynamic navigation

Compare this to React (React Router) or Vue (Vue Router) — you'll see that Blazor's approach is simpler for basic CRUD apps because the routing is convention-based and built into the framework.

## Key Decisions Made

1. **Render Mode: Auto (Hybrid)**
   - Server renders the page on first load (fast TTL, no JS download)
   - Interactive components (.razor with @rendermode InteractiveServer) use WebAssembly islands
   - Balances performance and interactivity

2. **Component Architecture**
   - Header, Sidebar, Content as separate, composable components
   - PartsGrid manages state and pagination
   - PartsForm is a reusable child for Add/Edit
   - ConfirmDialog is a reusable confirmation modal

3. **Styling**
   - Scoped CSS in each component (no external CSS file needed)
   - Minimal, plain design (no MUI/Vuetify) — this is intentional for the bake-off
   - Responsive layout with flexbox

4. **API Client**
   - Centralized PartsService for all HTTP calls
   - Registered in DI container
   - Handles pagination, filtering, sorting via query params

5. **Validation**
   - Inline, client-side validation in the form component
   - Rules match the spec (SKU 3–20 chars, Price > 0, etc.)
   - Form submission disabled until valid

## Routing in Blazor vs Other Frameworks

### What You're Testing

By building a multi-page app (Home → Parts Manager → Contact Us → Reports → Settings), you get real insight into how Blazor handles routing. Here's how it compares:

| Aspect | Blazor | React | Vue | Angular | Next.js |
|--------|--------|-------|-----|---------|---------|
| **Router setup** | Built-in to framework | Need React Router (separate) | Built-in (Vue Router) | Built-in (Angular Router) | Built-in (file-based like Blazor) |
| **Route declaration** | `@page "/path"` directive | `<Route path="/path" />` in JSX | `path: '/path'` in config | `path: 'path'` in config | File-based in `app/` folder |
| **Active link detection** | `NavigationManager.Uri` | Check window.location or useLocation() | `useRouter()` hook | `routerLinkActive` directive | Built-in highlight |
| **Programmatic navigation** | `Navigation.NavigateTo()` | `navigate()` from useNavigate() | `router.push()` | `router.navigate()` | Link component + onClick |
| **Learning curve** | Low (convention-based) | Moderate (requires Router setup) | Low (official Router) | Moderate (RxJS patterns) | Low (file-based) |
| **Bundle impact** | Small (built-in) | +60KB (React Router) | Smaller (official) | Medium (Angular Router) | Minimal (built-in) |
| **Performance** | Fast (server render → WASM) | Fast (client-side) | Fast (client-side) | Moderate (depends on module loading) | Very fast (server-side render) |

### Key Observations from Your Bake-Off

When you test the routing, pay attention to:

1. **How intuitive is the routing syntax?**
   - Blazor: Just add `@page "/contact"` at the top — very simple
   - React: Need to understand Router wrapping, Route components, hooks

2. **How easy is it to highlight the active link?**
   - Blazor: Inject `NavigationManager`, check `Uri.EndsWith()`
   - React: Need custom logic or a library hook
   - Vue: Has built-in helpers for this

3. **Performance of navigation**
   - Blazor with Server rendering: Initial page is fast, transitions use WASM (instant)
   - React SPA: All routes load instantly (client-side)
   - Next.js: Server renders each page (slightly slower but SEO-friendly)

4. **Code organization**
   - Blazor: One file per page with scoped CSS and C# logic
   - React: Often separate files for components, routing config, styles
   - Vue: Single-file components (similar to Blazor)

## Troubleshooting

**"Module not found" errors?**  
Run `dotnet restore`

**Hot reload not working?**  
Restart `dotnet watch run` or ensure you're in Debug mode

**CORS errors from json-server?**  
Ensure json-server is running on `localhost:4000` and configure CORS in `Program.cs` if needed

**Form not updating on input?**  
Ensure component has `@rendermode InteractiveServer` and use `@bind` for two-way binding

**API calls fail with 404?**  
Verify json-server is running and endpoints match the PartsService URLs
